URL 매개변수로 자동 설정하기

페이지 접속 시 URL 쿼리로 API Key를 자동 주입할 수 있습니다:

...?apiKey=YOUR_NEIS_KEY
입력하신 Key는 웹 브라우저의 로컬 저장소(localStorage)에만 안전하게 저장되며 외부 서버로 전송되지 않습니다.
